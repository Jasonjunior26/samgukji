# UI 시트 전수조사 — 어떤 커맨드가 장수 선택을 정말 필요로 하나 (2026-10-22, 읽기 전용)

대상: `samguk_v108.html`의 가로 UI 탭 7개(군사·내정·인사·외교·계략·교역·자료). 코드는 수정하지 않았다. 설계 `docs/UI_시트_개편_설계.md` §2-5·§4가 기다리던 조사다. 줄 번호는 2026-10-22 기준이며, 같은 함수가 여러 번 정의된 곳은 **마지막(유효) 정의**를 적고 래퍼는 괄호에 썼다.

## 요약

1. **장수 인자를 쓰지 않는데 장수 목록을 띄우는 항목 (확인형/정보형 전환 후보)**: 병법(9188), 도시 정찰(첩보, 9190), 서원(내정 탭, cmdAcademy 3111), 시설 건설의 감독(9147), 상거래(교역, 12588), 외교 선물(`ACT.dpT`). 장수는 `acted` 표시와 경험치뿐이다.
2. **거의 안 쓰는 항목 (개성 한 가지만 영향)**: 징병(모병가, 비용 −30%·한도 +30%)·용병(경험치만). 단 "한 명당 N명"이라 장수 수가 곧 징병 횟수다. 장수 목록 대신 "횟수/수량 입력"으로 바꾸는 방안이 있고, 결정이 필요하다.
3. **수송**(`openConvoy`, 8122)은 이미 장수 없는 시트(받을 도시·금·군량)이나, 군사 메뉴의 `수송` 행은 8610 래퍼가 제거해 **현재 메뉴에서 닿지 않는다**(이동 시트가 흡수). 코드는 죽은 경로.
4. 장수 능력이 성공률·이득을 바꾸는 **목록형 유지** 항목: 훈련·수련·수색·정찰(인재)·등용·계략 전부·외교 선물 제외 전부·개발·상업·치수·성벽·시주·진휼·토벌·군비·공방·교역 학습/친교.
5. 장수가 **대상**(효과를 받는 쪽)이라 목록이 필수: 포상·면담·임명·해고·유학·교습·사제·대련·관심 인물(조회).
6. 이미 장수 목록이 없는 시트: 세율, 군량 매매(8817), 승급(9158), 수송(8122), 시세표(12266), 교역 효과 버튼 묶음(`trFxDo`, 13523), 자료 탭 6개.
7. **혼합형** 3개: 이동(8574/8884)·출진(7543)·군단 편성(8399). 장수가 필수인 부분과 수치/도시 선택이 섞여 있어 "목록형"이되, 이동은 금·군량만 보낼 때 장수를 안 고르게(현재도 가능, 10% 손실) 안내를 바꿀 수 있다.
8. 미확인: 인재 정찰의 능력치 영향(천거 개성만 확인), 매수·첩보망의 외교·계략 세부 효과 수치, `opsOpen`(운영 설정)·국책(10234)은 장수 목록이 없음만 확인.

## 읽는 법

- **장수 영향**: 능력 = 능력치/개성이 결과를 바꿈 / 표시 = `acted`·경험치뿐 / 대상 = 효과를 받는 쪽 / 없음 = 인자 자체가 없음.
- **권고**: 목록형 유지 / 확인형(작은 카드, 수치·대상만) / 정보형(조회).
- 메뉴 정의 위치: 군사·인사·계략 `ACT.cmd`(7790 + 래퍼 8039·8434·8610·8807·9197·13657·13670 `s11Menu`), 내정은 `devTabM` 12탭(8279 + 8673·8831·9164), 외교 `openDiplo`(9102 래퍼), 교역 `openTradeCmd`(13650)·`openWorldTrade`(12573), 자료 `s7TabBody`(13422).

- 확인형 전환: 병법, 도시 정찰, 서원, 시설(감독 제거 또는 선택), 상거래(장수 선택 생략), 외교 선물. 모두 `acted` 소모 규칙을 어떻게 할지 먼저 결정(장수 한 명이 소모되지 않으면 월 행동 총량이 늘어남).
