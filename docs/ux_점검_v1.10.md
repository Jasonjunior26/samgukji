## 4. 비고·미확인
- `s7Capture`로 패널에 펼쳐지는 시트 본문의 실제 가로 도크 표시는 코드상 body만 쓰므로 시트 제목은 패널에서 안 보임. 같은 시트가 도크로 열릴 때(예: 직접 `ACT.cmd`)는 제목이 보임 — 둘의 차이는 확인 못 함.
- 시트 겹침 수 상한(`UI.sheets` depth)과 모든 시트에서 되돌아가기 누름 시 이전 상태 복원 여부는 미확인.
- 위 줄 번호 중 `9146`(DEVTABS)과 `7800` 메뉴는 래퍼가 여러 겹이라 실제 화면에 나오는 행은 래퍼 적용 후이며, 직접 화면 대조는 하지 않음.
