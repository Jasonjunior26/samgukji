# 전투 v4 설계 — 조조전식 전면 개편 (초안)

> 2026-10-15 초안, 같은 날 1차 수정. 참고: `docs/조조전_리서치.md`.
> 목표: 전략 화면과 주고받는 데이터는 그대로 두고, 전투 안쪽의 규칙·화면·연출은 조조전처럼 새로 만든다.
>
> **1차 수정에서 정한 것**
> - 그래픽과 진행 방식은 조조전을 최대한 살린다.
> - 맵은 조조전 형태: 위에서 내려다보는 시점, 48px 정사각 칸, 화면보다 큰 스크롤 맵, 전투마다 크기가 다름.
> - 부상병은 성 안에 있을 때만 조금 회복된다.
> - 동시 진행(삼국지9식)은 없애고 조조전식 차례 방식 하나로 정리한다.

## 0. 원칙
1. **겉 계약은 유지한다.**
   - 입력: `startBattle(att, fromCn, toCn, aUnits, food, playerSide, defMode, policy)`
   - 출력: `finishBattle() → { win, msgs, report, playerWon }`
   - `B.units[].troops / max / dd / dt / k / fled`, `B.captured`, `B.rescue`도 같은 뜻으로 채운다.
   - 이렇게 하면 출진 편성, 포로, 인연, 경험치, 점령 처리는 손대지 않아도 된다.
2. **조조전의 손맛을 가져온다.**
   - 한 부대씩 이동 → 행동.
   - 상성·지형·날씨가 맞물린다.
   - 맵 위에서 바로 짧고 빠르게 연출한다.
   - 출진 전 작전 선택에 따라 전투가 달라진다.
3. **이 게임의 정체성은 지킨다.**
   - 병력이 곧 HP다.
   - 군량이 곧 제한 턴이다.
   - 군비 수준이 곧 병과 단계다.
   - 장수의 6능력, 특기, 개성, 조합, 전법은 계속 쓴다.
4. **코드는 덮어쓰기 층을 끊는다.**
   - 현재 전투는 v2 → v3 → v81(동시 진행) → v91~v102 래퍼가 겹겹이 쌓여 있고, 같은 이름의 함수 선언도 중복돼 있다.
   - v4는 **마지막 `<script>` 블록 하나**에 새로 짓는다. `startBattle = function…`처럼 직접 대입하고, 앞선 래퍼를 감싸지 않는다.
   - 그림(v97 병종 4방향, SD 초상 병사, 정예 그림, 지형 그림)과 소리는 재사용한다.

## 1. 부대와 수치

### 1.1 부대
- **1부대 = 유닛 1개 = 주장 1명.** 맵에는 주장 캐릭터만 나온다.
  - 부장(`vg`, `st`, `jg`)은 유닛으로 나오지 않는다. 보좌 효과(기존 특기·조합·궁합)는 그대로 부대 수치에 반영된다.
- **주장을 누르면 부대 정보 창**이 열린다.
  - 위: 주장 초상, 이름, 병과·단계, 병력 바(부상병 포함 표시), MP 바, 사기.
  - **종합 능력치**: 공격 A / 방어 D / 정신 I / 순발 E / 사기 M. 부장 보좌, 조합, 특기, 병과 등급·단계, 지형, 상태 보정을 모두 합친 **최종값**이다.
    - 숫자 옆에 기본값과의 차이를 작게 표시한다(예: `공격 112 (+14)`).
    - 숫자를 누르면 내역을 펼친다: 주장 기본값, 부장 보좌, 조합, 지형 등.
  - **부장 목록**: 이름만 한 줄로 보인다(예: `부장 관우 · 참모 서서 · 종군 미축`). 역할 이름은 기존 슬롯을 따른다(vg=부장, st=참모, jg=종군).
  - 아래: 특기·전법 이름, 걸린 상태이상과 남은 턴.
  - 적 부대도 같은 창을 보지만, 정보 지식(`kn`)이 낮으면 기존처럼 범위 값이나 `?`로 보인다.
- **HP는 병력**이고 최대치는 출진 병력이다.
- **부상병**: 받은 피해의 30%가 부상병(`u.wd`)으로 쌓이고, 나머지 70%는 전사다.
  - 부상병은 **성 안 칸(성내·본성)에 있을 때만** 매 턴 회복된다. 회복량은 최대병력의 2%이고, 그 턴 시작 때의 부상병 수를 넘지 못한다.
  - 「군의」 특기가 있으면 회복량이 3%. 성 밖에서는 어떤 방법으로도 회복되지 않는다.
  - 그래서 사실상 **수비측이 성에 틀어박혔을 때의 이점**이 된다. 공격측도 성 안에 들어가면 같은 규칙이 적용된다.
  - 전투가 끝난 뒤 남은 부상병은 귀환하지 않는다. 전략 쪽 병력 손실은 지금과 같은 감각으로 유지된다.
- **MP(책략치)** = 20 + 지력 × 0.6. 책사계는 ×1.6.
- **사기**는 기존 `u.mor`(0~100)를 쓴다. 0이 되면 퇴각한다.

### 1.2 능력치 변환 (조조전 5대 수치 ← 이 게임 6능력)
| 조조전 수치 | 공식 | 쓰임 |
|---|---|---|
| 공격 A | 무력×0.6 + 통솔×0.4 | 물리 피해 |
| 방어 D | 통솔×0.7 + 무력×0.3 | 물리 피해 감소 |
| 정신 I | 지력 | 책략 피해·명중·저항 |
| 순발 E | 무력×0.5 + 통솔×0.5 | 명중·회피·연속공격 |
| 사기 M | 부대 사기 | 회심, 책략 명중, 퇴각 |

각 값에 **병과 등급계수**를 곱한다: S 1.2 / A 1.1 / B 1.0 / C 0.9.
그다음 **단계 보정**(+0 / +8 / +16%), 진형·특기·조합·상태 보정을 차례로 곱한다.

### 1.3 공식 (조조전 공식을 병력제에 맞게 바꿈)
```
기준값   = (A×지형a − D×지형d) / 2 + 40            (최소 5)
물리피해 = 공격측 현재병력 × 0.10 × (기준값/40) × 상성 × 사기계수 × 난수(0.95~1.08)
사기계수 = 0.7 + 0.3 × (사기/100)
반격     = 물리피해 × 0.75  (반격에는 연속공격 없음)
회심     = ×1.5, 확률 f(공격측 사기 / 수비측 사기)
연속공격 = 같은 공격 한 번 더, 확률 f(공 순발 / 방 순발)
명중     = g(공 순발 / 방 순발) + 장비·특기.  대상이 혼란이면 100%
```
- `g(x)`: x≥2이면 100, 1≤x<2이면 10x+80, ½≤x<1이면 60x+30, ⅓≤x<½이면 90x, 그 미만은 30 (%).
- `f(x)`: x≥3이면 100, 2≤x<3이면 80x−140, 1≤x<2이면 18x−16, 그 미만은 1 (%). 실제로는 최대 40%로 자른다.
- **보정 기준**: 5000 대 5000, 능력이 같으면 한 번에 약 500(10%), 반격 약 375. 동급끼리 7~8번 주고받으면 무너진다(조조전 템포).
- 피해 예상 창: 명중 %, 예상 피해, 반격 여부·피해, 회심·연속 확률을 보여준다(기존 v92 예상 피해를 확장).

- **상성**:
  - 기병→보병·방진: ×1.2
  - 보병→궁병·공성: ×1.5
  - 궁병·궁기→기병: ×1.5
  - 보병→기병: ×0.6
  - 방진←기병: 받는 피해 ×0.7, 반격 ×1.3 (봉시 → 방원 반격이 크던 기존 규칙 유지)
- **단계 결정**: 출진 도시의 해당 병종 군비 0~59는 1단계, 60~119는 2단계, 120 이상이거나 「정예」로 지정되면 3단계. 군비가 높을수록 맵에서 병과 이름과 그림이 바뀐다(정예 그림은 그대로 재사용).
- 기존 특기는 그대로 연결한다: 돌격→기병, 신궁→궁병, 철벽→방진, 산악→산악병, 공성→공성, 수전→수군, 신속→이동 +2.

### 3.1 맵 형태 (조조전식)
- **위에서 내려다보는 시점**, 48px 정사각 칸.
  - 지금 작업판의 비스듬한 시점(v-시험판)은 버린다.
  - 지형 그림은 조조전처럼 칸 경계가 드러나지 않게 이어지는 도트 타일로 그린다. 숲·산·성벽은 옆 칸과 이어지는 모양으로 자동 선택(오토타일).
- **화면보다 큰 맵을 끌어서 스크롤한다.** 전투 규모에 따라 크기가 다르다.

  | 규모 | 크기 (가로×세로) | 언제 |
  |---|---|---|
  | 소 | 20×16 | 양쪽 합쳐 6부대 이하의 야전 |
  | 중 | 24×20 | 일반 야전, 관문, 나루 |
  | 대 | 30×24 | 공성전, 양쪽 합쳐 12부대 이상 |

  - 조조전 실제 맵 크기는 출처로 확인하지 못했다. 위 값은 기억에 기댄 것이니 플레이 영상으로 맞출 것.
- **휴대폰 표시**: 기본 배율로 가로 약 8칸이 보인다.
  - 두 손가락으로 확대·축소(0.6×~1.5×).
  - 오른쪽 위 작은 **전체 지도**를 누르면 그 위치로 이동.
  - 조조전처럼 아군 차례가 시작되면 다음 행동 가능한 부대로, 적 차례에는 움직이는 적 부대로 카메라가 따라간다.
- 맵 생성은 기존 `genMap(terr)`의 지형 유형(평지/산악/강변/관문/나루/남만)을 이어받는다.
  - 성 배치(CASTLE)는 큰 맵에 맞게 다시 그린다: 성벽으로 두른 성 안, 성문 2~3개, 본성.
  - 마을 1~3개, 진채(양쪽 배치 구역 근처), 계절 설원을 더한다.
  - 공격측은 맵 한쪽 끝, 수비측은 성 또는 반대쪽에 둔다(조조전처럼 서로 멀리서 시작해 진군).
- 역사 전투(고정 맵)는 만들지 않는다. 모든 전투는 도시 지형에 따라 자동으로 생성한다.

## 4. 턴 구조
- **아군 → 우군(동맹 원군) → 적군** 순서. 한 턴은 하루다(군량·계절 계산과 맞춤).
- **제한 턴** = min(30, 출진 군량 ÷ 하루 소모량). 상단에 `제 7턴 / 22턴`처럼 표시한다. 공격측이 제한 턴 안에 목표를 이루지 못하면 퇴각하고, 수비측이 이긴다.
- 조기 승리 보상: 남은 턴 × (군량 일부 반환 + 공적 보너스).
- 날씨는 맑음/흐림/비/눈. 3턴마다 바뀔 수 있다. 비가 오면 화계가 불가하고 궁병 명중 −10, 눈이 오면 화계 불가에 이동 비용 +1.
- 기존 동시 진행(v81)은 **삭제**하고 조조전식 차례 방식 하나만 둔다. 대신 "전군 위임"과 "적 턴 빠르게"를 둔다.

### 4.1 전투 한 판의 흐름 (조조전 순서)
1. **작전 회의 장면**: 막사 배경에서 초상 대화를 나누고 작전을 고른다(10.2).
2. **출진·배치**: 정해진 배치 칸 안에서 부대 위치를 바꾼다. 조조전의 출진 장수 선택 뒤 배치에 해당.
3. **개전 연출**: 카메라가 적 총대장 쪽으로 이동해 적의 대사를 보여준 뒤 아군 쪽으로 돌아온다. 화면 가운데에 승리·패배 조건 창이 뜬다.
4. **턴 반복**: 아군 → 우군 → 적군. 턴이 바뀔 때마다 "제 N턴 / 아군 차례" 띠가 뜬다.
5. **도중 이벤트**: 원군 등장, 복병, 장수끼리 인접할 때의 대화, 일기토.
6. **승리·패배 연출**: 승리 대사 → 결과 창(격파 수, 공적, 얻은 것) → 전략 화면.

## 5. 명령 흐름 (조조전 그대로)
1. 부대를 누르면 이동 가능 칸(청록)과, 이동 후 공격할 수 있는 칸의 테두리(빨강)가 뜬다.
2. 칸을 누르면 부대가 경로를 따라 미끄러져 이동한다(v94 연출 재사용).
3. 부대 옆에 **행동 메뉴**가 뜬다: `공격 · 책략 · 도구 · 일기토 · 대기`. 행동하기 전에는 `취소`로 이동을 되돌릴 수 있다.
4. 대상을 고르면 예상 창이 뜨고, 확정하면 연출이 나온다. 행동을 마친 부대는 회색이 된다.
5. 적을 길게 누르면 그 적의 이동·공격 범위를 보여준다.
6. 하단 고정 줄: `턴 종료 · 전군 위임 · 전황 · 속도(1×/2×/생략)`.

## 6. 책략 (MP 사용, 지형·날씨 조건)

| 계통 | 책략 | MP | 사거리 | 범위 | 조건 | 효과 |
|---|---|---|---|---|---|---|
| 화계 | 초열 / 화진 / 화룡 | 6/12/20 | 4/4/3 | 단일/십자/십자 | 평지·초원·숲·성내·마을, 비·눈 불가 | 피해, 대상 칸에 불 1~2턴 (기존 `burn`) |
| 수계 | 탁류 / 수진 | 6/12 | 4 | 단일/십자 | 강·여울·습지에 있거나 그 옆 | 피해 + 사기 −5 |
| 낙석 | 낙석 / 산사태 | 6/12 | 4/3 | 단일/십자 | 대상이 언덕·산·그 옆 | 피해 (위력 높음) |
| 고무 | 고양 / 환성 | 6/16 | 4/3 | 십자/사각 | — | 사기 +15, 3턴 |
| 견고 | 견고 / 강진 | 6/16 | 4/3 | 개인/십자 | — | 방어 +20%, 3턴 |
| 기동 | 강행 | 8 | 3 | 개인 | — | 이동 +2, 1턴 |
| 진정 | 진정 / 위무 | 8/14 | 3/4 | 개인/십자 | — | 사기 +20, 혼란 해제 (병력 회복 책략은 없음) |
| 방해 | 혼란 / 발묶기 / 도발 / 욕설 / 봉책 | 8 | 4 | 단일 | — | 행동 불가·반격 불가 / 이동 불가 / 끌어당김 / 방어 −30% / 책략 불가 (기존 계략 5종 + 봉책) |

- **책략 피해** = 대상 최대병력 × 0.08 × 위력 × ((I − I′)/3 + 40)/40. 큰 부대에 효과가 크다.
- **책략 명중** = g((정신+사기) 비율) × 책략 계수(1 / 0.9 / 0.8), 특기 보정 포함(신산 +15, 화계 +30, 간파는 면역).
- **습득**: 지력 50 이상이면 1단계, 70 이상이면 십자 범위, 85 이상이면 상위 책략. 계략 특기가 있으면 해당 계통을 미리 해금한다. 책사계는 전 계통을 쓴다.
- **전법(v80·v102)**은 **장수 고유 비기**로 남긴다. MP가 아니라 기존 게이지를 쓰고, 행동 메뉴의 `책략` 맨 위에 「청룡언월(전법)」처럼 표시한다.
- **동남풍 이벤트**: 적벽(208년 11월, 제갈량 출진)이면 화계 명중 100%, 위력 ×1.5 (기존 `eastwind` 유지).

## 7. 도구
- 장수가 가진 보물의 기존 효과는 상시 적용된다.
- 전투 소모품은 출진할 때 군량·금으로 챙겨 간다.
  - 「탁주」: 사기 +20
  - 부상병을 되돌리는 도구는 없다(성 안에서만 회복).
  - 「해독약」: 상태이상 해제
- 부대당 최대 2개.

## 8. 일기토
- **신청**: 인접한 적 장수에게 행동 메뉴의 `일기토`로 신청한다. 수락 판정은 기존 `duelAccept`를 쓴다(방진은 거부, 무력 차이와 특기 「일기」 반영).
- **연의 일기토**: 정해진 장수 쌍이 처음 인접하면 자동으로 발생한다(관우–화웅, 관우–안량·문추, 허저–마초, 장비–여포 등). 장수 쌍 표는 DB에 넣는다.
- **연출**: 맵 위에 띠 화면이 뜨고 두 장수가 마주 본다. 3~5합을 주고받는다(합마다 막기/밀림/회심 동작). 이어 대사, 결과 순서.
- **결과**: 진 쪽 부대는 사기 −30. 장수는 부상, 퇴각, 포로, 드물게 사망(기존 확률 유지). 이긴 쪽 부대 사기 +15.

## 9. 연출 사양 (핵심)

### 9.1 공격 한 번의 타임라인 (1× 기준)
| 시간 | 공격측 | 수비측 | 화면 |
|---|---|---|---|
| 0ms | 대상 쪽으로 방향 전환 (4방향 그림) | | 아래 **교전 창**이 미끄러져 올라온다 (양쪽 초상·병과·병력 바·사기) |
| 150 | (회심이면) 흰 번쩍임 2회 + 컷인 "받아라!" (초상 + 한 줄, 500ms) | | |
| 200 | 공격 동작. 근접은 반 칸 돌진 후 복귀, 궁은 화살 투사체 300ms, 투석은 포물선 | | |
| 450 | | 명중: 피격 동작(뒤로 밀림·빨강 깜빡임). 빗나감: 옆으로 반 칸 회피 | 큰 빨간 피해 숫자 `−520`, 빗나감이면 `회피` |
| 450~850 | | | 교전 창 병력 바가 줄어듦 (숫자도 같이 감소) |
| (연속) | 같은 동작 반복 + `연속!` 표시 | | |
| (반격) | | 역할을 바꿔 반복, 피해 숫자는 주황 | |
| 끝 | | 병력 0 또는 사기 0이면 퇴각 대사창 → 깜빡이며 사라짐 | 교전 창이 내려감 |

- 한 번 주고받는 데 약 1.2초. 2×는 0.6초, `생략`은 숫자만 표시한다. 적 턴은 기본 2×.
- 퇴각 대사는 장수별 고유 대사표를 쓰고, 없으면 성향(개성)별 기본 대사를 쓴다.
- 책략은 대상 칸 위에 이펙트를 600ms 재생하고, 여러 대상에 동시에 피해 숫자를 띄운다.
  - 화계: 불꽃 기둥
  - 수계: 물결
  - 낙석: 바위 낙하
  - 혼란: 소용돌이
  - 회복: 녹색 빛
- 이벤트 대화는 초상 + 이름 + 대사창 형식이다. 맵 유닛이 대사에 맞춰 이동·방향 전환·느낌표 동작으로 연기한다.

- **부대 그림**:
  - 48px 도트 병사 1명이 부대를 나타낸다(조조전처럼 장수 1인 그림, 병과별 모양).

|---|---|---|---|

| 우회 | 산·숲이 있는 맵 | 배치 구역이 측면으로 바뀜 | 제한 턴 −4 |
| 화공 | 맑음, 화계 가능 장수 | 시작할 때 적 진채 칸에 불 | 실패 확률(군사 지력) |

- 역사 전투는 넣지 않는다. 연의 분위기는 연의 일기토(8장)와 기존 역사 이벤트(동남풍 등)로만 낸다.

## 11. AI
부대마다 **성향**을 붙인다(조조전 적 AI 유형).
- **돌격**: 가장 점수가 높은 적에게 간다.
- **요격**: n칸 안에 적이 들어와야 움직인다. 수비측 기본값.
- **고수**: 거점(성문·본성·진채)을 떠나지 않는다.
- **호위**: 총대장 주변 2칸을 지킨다.
- **목표**: 특정 칸으로 향한다(관문 돌파, 탈출).

행동 점수 = 예상 피해 − 예상 반격 + 막타 보너스(×1.5) + 상성 + 지형 이점 − 위험 칸 노출.

책략 AI는 다음 순서로 판단한다.
1. 아군 병력이 40% 아래면 회복.
2. 적이 3개 이상 모였으면 범위 책략.
3. 대상이 강한 단일 적이면 혼란.

## 12. 결과 반영 (finishBattle)
- 출력 형식은 지금과 같다.
- **경험치**: 공격·막타·반격은 무력/통솔, 책략은 지력, 회복·고무는 매력 쪽으로 기존 `addExp`에 기여도에 비례해 나눈다.
- **MVP** = 준 피해 + 격파 × 1000(현행) + 책략 기여.
- 귀환 병력 = 남은 병력. 부상병은 귀환하지 않는다.

## 13. 자동 전투와의 정합
`autoBattle` / `winChance`(AI끼리 싸우거나 위임할 때)가 v4 수동 전투와 비슷한 결과를 내도록 다시 맞춰야 한다. 그렇지 않으면 군단 AI의 출진 판단(55% 기준)이 어긋난다. 방법: v4 규칙으로 AI 대 AI 시뮬레이션을 수백 판 돌려 계수를 맞춘다.

## 15. 정해 주셔야 할 것
**정한 것**
- 그래픽·진행 방식은 조조전식.
- 맵은 조조전 형태(48px 칸, 스크롤, 규모별 크기).
- 부상병은 성 안에서만 소량 회복.
- 동시 진행은 삭제.

- 1부대 = 주장 1명이 유닛. 부장은 이름만 보이고, 주장을 누르면 종합 능력치가 보인다.
- 추행은 궁기병으로 바꾼다.
- 역사 전투는 뺀다.

**남은 것**: 없음. 1단계(규칙 핵심)부터 구현을 시작할 수 있다.
