# 교역 × 군주 성향 설계 (2026-10-20, Sonnet 초안, 미빌드)

목적: 복구한 세계 교역(v106 작업)을 "누구나 전부 할 수 있는" 방식에서 **군주 성향(뿌리)별로 열리는 결과가 다른** 방식으로 바꾼다. `국책_설계.md` §15~17의 뿌리·성향 구조와 합친다. **html은 건드리지 않는다.**

## 1. 사용자 결정 (2026-10-20)
1. 새로 논의한 방향(성향별로 제한적이고 서로 다른 결과)으로 발전시킨다. 기존 개발은 일부만 차용하고 전부 쓸 필요는 없다. 성향마다 **한 가지만이 아니라 2개 정도는 열어 준다**.
2. 그러므로 5a 미해결(일본도 +2, AI 교역 순이익 음수)은 **고치지 않는다**. 경제 구조를 새로 설계하기 때문이다.
3. 빌드할 때 파일명은 **`samguk_v107.html`** 로 확정한다(v106은 건너뜀. 기존 문서의 v106 표기는 복구본 이름이라 그대로 둔다).

## 2. 원칙
- 지금 v106은 교역도만 올리면 인물·개성·병종·차익을 **모두** 얻는다. 뿌리가 하나뿐인 내정 경쟁과 같은 구조라 모두 같은 길로 간다.
- 교역 결과를 갈래로 나누고, 군주의 **주 뿌리가 갈래 2개**를 연다. 나머지는 닫힌다(§4).
- 열리는 갈래는 **서로 다른 병목**을 건드려야 한다(`국책_설계.md` §11): 인물은 인재, 병종·물자는 전투력, 차익·용병은 금이다.
- 출병 한도나 대기 비용은 두지 않는다(사용자가 이미 기각).

## 3. 교역 결과 6갈래 (기존 설계에서 뽑음)
| 갈래 | 내용 | 기존 위치 |
|---|---|---|
| 인물 | 교역도 60/80/100에 외국 재야 발견(나라별 6명) | `세계교역_설계.md` §3·4 |
| 개성 | 학습으로 특수 개성·특기 습득(교역도 20↑) | §2-2 |
| 병종 | 학습으로 특수 병종 해금(40↑, 세력 1회) | §2-2 |
| 물자 | 특산품(철·명마·화약·일본도 등)을 장비·정예에 투입 | 5a(재료 투입) |
| 차익 | 상거래로 금을 번다. 군량↔금 교환 포함 | §2-1 |
| 용병 | 용병(`mercCost`=징병×3)과 교역 군단으로 병력을 조달 | `상거래_2단계_설계.md` 4-1 |

## 4. 뿌리별 배정 (제안)
| 주 뿌리 | 열리는 2갈래 | 닫히는 것 | 플레이 모양 |
|---|---|---|---|
| 인재×내정 | 인물 + 개성 | 병종, 용병 | 친교·학습으로 교역도를 올려 외국 인물을 모은다. 금은 덜 번다 |
| 정예 | 병종 + 물자 | 인물, 차익 | 특산 물자와 특수 병종으로 소수 정예를 만든다 |
| 신뢰·외교(교역) | 차익 + 용병 | 인물, 병종 | 금으로 병력을 사서 쓰는 얇고 빠른 길(4-1 교역형) |
| 통치 흡수 | 개성 + 차익(군량 교환) | 병종, 인물 | 수비 특기와 군량 교환으로 점령지를 안정시킴 — **교역과 접점이 약해 미정** |

- **부 뿌리**: 주 뿌리 갈래 외에 부 뿌리의 첫 갈래 1개를 **절반 효율**로 연다(그래서 최대 2+1). 나머지는 닫힘.
- 닫힌 갈래는 영구 차단으로 둘지, 교역도 20까지만 맛보기로 둘지는 미정(§7).
- 상대국의 특산(kor 철·산성수비·맥궁병, jpn 일본도·인술·사무라이, eeu 명마·공포·후사르, weu 향료·기사도·원탁기사, usa 화약·속사·총사)도 뿌리마다 어울리는 상대가 갈린다 → 어느 나라와 교역할지가 두 번째 선택이 된다.

## 5. 구현 방향 (병합 뒤 확인할 것)
- 교역 명령 앞에 게이트 하나 `trOpen(fid, kind)`를 두고, 모든 갈래가 그 함수를 거치게 한다. 뿌리 값은 `국책_설계.md` §17-2의 뿌리 선택(기존 `trIncl(fid)`를 확장)에서 가져온다.
- AI는 교역도 증가율과 학습 행선지를 뿌리별로 다르게 한다(전체 +2/월 폐지). 플레이어도 같은 게이트를 쓴다.
- 함수 이름과 위치는 v106 코드에서 grep으로 정하며, 병합 전이라 **미확인**.

## 7. 사용자 결정이 필요한 것
1. 부 뿌리의 절반 효율 갈래(2+1)가 좋은가, 아니면 주 뿌리 2갈래만으로 충분한가?
2. 닫힌 갈래는 영구 차단 vs 교역도 20 맛보기 중 무엇인가?
3. 통치 흡수 뿌리에 교역 갈래를 무엇으로 줄까(제안: 개성 + 군량 교환)?
4. 플레이어는 뿌리를 자유롭게 고르는가, 성향·시작 조건으로 정해지는가?
