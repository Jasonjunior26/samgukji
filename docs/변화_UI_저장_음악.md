## v1.3 설계 (2026-10-19, 미빌드) — 장수 전용 그림 폐지, 1품·군주만 고른 그림+변형으로 화려하게
### 변경 사항 (설계 확정, `samguk_v105.html`에는 아직 반영 안 함)
- 문제: `JOJO_UNITS.uniq` 28명(군주 6 · 기병 7 · 보병 13 · 책사 2)만 이름으로 전용 그림이 걸려, 이 게임에서 일반 장수인 조조가 군주 그림으로 나오고 다른 군주(동탁·마등 등)는 허전했다.
- 결정 1: 이름 기반 전용 그림은 **모두 폐지.** 그림은 병과·단계(레벨)·색으로만 정한다. `jojoIndex`(12775줄)의 `J.uniq` 분기를 지운다.
- 결정 2: **각 진영 1품 장수**(`g.rank === 1`, `RANKS`(3077줄), 진영당 1~3명)와 **군주**(`isRuler`)만 기존 그림 중 고른 것을 쓰고, 런타임 변형으로 화려하게 한다. 이름이 아니라 신분이 기준이라 모든 진영이 같은 규칙을 받는다.
- 전용 28개 검토 결과 (사람 특정도):
  - 쓴다(특정도 낮음): **128**(금갑 기마, 손견·손책·손권이 이미 공유) → 1품 기병·궁기병 / **135**(깃털 투구 금갑 기마, 원소) → 군주 전 병과 / **133**(청록 외투 갑옷 보병, 육손) → 1품 보병·방진·산악병·수군 / **124**(흰 도포 군사, 제갈량) → 1품 책사.
  - 제외(특정도 높음): 관우(청룡도·녹포)·조운·장비·유비·여포(붉은 갑옷)·주유·사마의, 조조(108)·하후돈·장료(단계 3장 묶음이라 1품 쓰임새 불명), 허저·전위(상의 노출), 초선·축융·몽매·헌제(비전투 외형), 서서 어머니·감부인·미부인·추부인·조숭·조식(똑같은 평민 137 6명).
  - 1품 궁병은 맞는 전용 그림이 없다. 일반 궁병 그림에 변형만 입힌다.
- 변형(새 그림 없이 캔버스로): 1품 = 금색 윤곽 발광 + 금빛 틴트 약 0.16 + 금테 받침 / 군주 = 주황·금 이중 발광 + 틴트 약 0.24 + 금테 받침 + 반짝이 점. `unitCan`의 `source-atop` 틴트(12807줄)와 같은 방식으로 구현할 수 있다.
- **주의(미해결)**: 전용 그림은 아군·적군 색 구분이 없다(`player === enemy`). 변형을 입힌 그림에는 **진영색 받침**을 반드시 깔아 아군/적군을 구분해야 한다(시안은 아군 파랑).
- 선택: 아틀라스에서 쓰지 않을 전용 그림 행을 빼면 PNG가 줄어든다(`tools/jojo_assets.py`의 `uniq` 수집을 124·128·133·135 4개로 줄임). 필수는 아니다.
