## 0. 요약 답변 (덕화 추가 질문)
- **진휼·시주 → cmdLoy 연동: 정상.** `cmdRelief`(5236)·`cmdCharity`(5235)는 모두 `cmdLoy(...)`를 호출하고, 덕화 +20% 래퍼는 `cmdLoy = function` 재할당(12971)이라 호출 시점에 해석되어 UI·AI 전부 래퍼를 지난다. 다중 선택 `run`(8276)도 `cmdRelief/cmdCharity` 경유.
- **AI 덕화의 진휼은 cmdLoy를 거친다.** 호출처: 2857(`cmdRelief`→cmdLoy), 5365·5893(직접 `cmdLoy`), 6111(cmdDraft 앞 민충 보정), 6163(군단 `loy` 작업). 5995는 조언 문구만. 민충을 `c.loy +=`로 직접 올리는 우회 경로는 못 찾음(미확인: 6177 `stagingCivic` 내부는 끝까지 읽지 않음).
- **tuhangStep(12907) 연동:** 월 갱신 뒤(13018) 실행. 진휼·시주·덕치(+0.6/월, 6338)로 도시 민충을 80↑로 올리면 이웃 적 도시 민충 −0.8/월(대상당 최대 −2)·인구 0.3% 이전. 적 도시 민충 30 미만 4개월 + 이웃 우리 도시 70↑ → (30−민충)/60 확률로 투항. `openTuhangInfo` 문구(13064~)와 수치(80·70·30·4개월·0.8·2·0.3%·60%·12개월 2곳) **일치**.

## 1. 7탭 + 칩 + 시트 점검 (덕화 시점)
탭 본문은 `s7TabBody`(13393)가 `s7Capture`로 기존 `ACT.cmd(v)` 시트를 그대로 펼친다. 행은 `ACT.sub`(6819·7377·8050·8431·8607·8804·9142·9194 래퍼 체인)로 연결되며 **핸들러 누락은 없었다**(군사·인사·계략 행 전부 매핑 존재, 수송·장수 이동은 8610 정규식으로 숨김).

덕화 전용으로 보이는 행은 계략 탭 끝의 `민심 투항` 하나(`s7PlotRows` 13629 → `rtSub('민심')` 13034 → `openTuhangInfo` 13064, 동작함). 덕화에게 숨겨지는 행: `설득`(경륜), `동맹 이간`(상략).

## 2. 발견 항목 (줄 · 문제 · 한 줄 수정 제안)

### A. 동작·표시 불일치
1. **8260~8265, 8274 `devPlan` 미리보기가 덕화 +20%를 반영하지 않음.** 시주·진휼 다중 선택의 `민충 X → 약 Y`와 장수별 `+N`은 `loyGain`만 쓰고, 실제 결과는 래퍼(12971)가 더 올림. → 덕화면 `v += Math.round(v*0.2)`를 미리보기에도 적용(또는 보너스 계산을 공용 함수로).
2. **12688 `RT_DESC` 덕화 "투항·진휼·시주 ×1.2"는 부정확.** ×1.2는 진휼·시주 증가분(12971)뿐, 투항은 배율 없음. 노선 선택 시트(13026)에 그대로 노출. → `'진휼·시주 민충 +20%, 이웃 성 민심 투항, 국책 덕치·법치·둔전제'`로.
3. **13396 외교 탭 `덕화 노선` 행이 실행 행처럼 생겼으나 읽기 전용.** `rootMenu`(13846)는 `openRootDetail` 설명 시트만 연다(상단 칩과 중복). → `small`에 "설명 보기"를 명시하거나 `s7note`로 교체.
4. **13394 내정 탭 `내정` 행 설명이 "개발·상업·성벽·군량 매매"뿐.** 실제 시트(8273)는 12탭(치수·서원·시설·승급·공방·시주·진휼·세율 포함). 덕화 핵심 시주·진휼이 안 보임. → 설명을 `개발·상업·치수·성벽·시주·진휼·세율 등`으로.
5. **TIPS.t_계략(13651 부근)의 "내 노선으로 쓸 수 있는 계략만 보입니다"는 사실과 다름.** 가려지는 것은 노선 전용 행(설득·동맹 이간·민심)뿐이고 매수·이간·내통은 모든 노선에 보이며 비용 ×1.4·성공률 ×0.7로 약해질 뿐(12707·12709). → "노선 전용 행은 해당 노선에만 보이고, 나머지 계략은 노선별 비용·성공률이 다릅니다."로.

- 플레이어는 `openEventQueueOrReport` 래퍼(13031)가 노선 미선택이면 `openRootPick`(13023, `noClose`)으로 막아 **노선 없이 플레이할 수 없다.** 노선 없는 상태는 고르기 직전·구 저장 불러오기 직후뿐. AI는 `RT_ASSIGN`(12692)에 없으면 능력 점수로 자동 배정(12719 부근; 전체 정독은 안 함, 미확인).
