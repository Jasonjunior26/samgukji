## v1.2 설계안 (2026-10-22, **미구현 — 빌드 지시 대기**) — 메뉴 정리 + 덕화 '베풂 파급'
### 사용자 지적 (v108 플레이)
- 계략 > 민심 투항: 클릭 안 됨(읽기 전용 정보 창인데 실행 행과 같은 모양), 도시별 문구 불일치("민충 100" / "민충 100 · 민충 30 이상").
- 교역: '품목 행동'이 교역 메뉴와 세계 교역 시트에 중복, 이름 모호. 군량 매매는 내정 소관인데 교역에 있음.
### 확정 방침
1. 교역 메뉴 3묶음: **해외 교역**(상거래·시세표·수송·학습·친교, 군량은 외국이 사 주는 나라에 한해 **'군량 수출'**로 개명) / **교역 효과**('품목 행동' 개명, 세계 교역 시트에서는 제거하고 교역 메뉴에 1회만) / 군량 매매는 **내정 매매 탭에만**(교역 메뉴에서 삭제).
2. 민심 투항 행을 계략에서 빼고 노선 칩 시트로 옮김. 표기 통일: `투항까지 N개월` · `투항 대상 아님(수도·면제 중·민충 높음)`. 민충 수치는 한 번만.
3. 행 종류 구분: 실행 버튼 / ⓘ 정보 / `>` 이동 (노선별 전수 점검은 `docs/메뉴_점검.md`).
4. **덕화 능동 행동 = 베풂 파급** (적 도시를 직접 건드리지 않음): 덕화 세력이 자기 도시에서 진휼·시주로 민충을 올리면, 그 도시와 인접한 적 도시의 민충이 따라 깎인다("저쪽은 베푸는데 우리는?").
   - 가안: 올린 민충 v당 적 도시 −0.1v(한 번에 최대 −2), 적 도시당 월 합계 상한 −3(기존 월 파급 −0.8/−2와 합쳐 월 −4 이내). 새 비용 없음(진휼·시주 비용 그대로). 덕화 ×1.2 기존 증폭과 곱하지 않음.
   - 조건: 행동한 도시 민충 70 이상, 인접 적 도시가 동맹이 아닐 것(기존 `rtOppAllied`), 투항 판정은 기존 규칙(30 미만 4개월) 그대로.
   - 후크: `cmdLoy` 성공 뒤 `tuhangStep`의 인접 순회식 재사용. AI 덕화도 같은 경로로 적용(AI 진휼 호출 경로가 `cmdLoy`를 거치는지는 **미확인**).
   - 검증 계획: 빌드 전 `tools/`에 투항 흐름만 측정하는 소규모 시뮬(덕화 vs 이웃 1~2세력, 24개월)으로 월 평균 민충 하락·투항 건수를 확인. 수치(−0.1v·상한 −3)는 가안, **미측정**.
- 전투 재측정: 해당 없음(전투 코드 무관).
- 관련 커밋: 없음(설계 단계).
