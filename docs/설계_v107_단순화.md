빌드는 사용자가 "빌드하자"고 한 뒤에만 한다. 줄 번호는 `grep -a -n`으로 다시 확인.

## 확정된 결정
- 용어: **뿌리 → 노선**, **갈래 → 없앰**(교역 품목을 "공통 / 노선 전용"으로만 구분).
- 교역: 커맨드에 **'교역'** 추가. **경륜·강병·덕화는 자기 전용 품목 1개만** 열림(경륜 인물·개성 / 강병 병종·물자 / 덕화 민생·보급). **상략은 전 품목**을 교역도 단계별로 차례로 엶(순서·문턱은 구현 때 확정). 군량 매매(금↔군량)는 원래 내정 '매매' 탭 기능이라 **그대로 두고 교역과 무관**(가로 '교역' 탭에 걸려 있던 '군량 매매' 행은 내정 쪽으로 정리). 상략이 여는 품목의 효과는 전문가 노선보다 낮게(예: 60%) 두어 "넓게 vs 깊게"를 맞춤 — 교역 시뮬로 확인 필요. 닫힌 품목은 숨김. AI도 자기 품목만 거래.
- 노선 전용 기능은 별도 '뿌리 메뉴'를 없애고 기존 커맨드로 흡수: 설득(경륜)·동맹 이간(상략)·민심 투항(덕화) → **계략**, 훈련(강병) → **군사**. 조건이 안 맞으면 행을 숨기고 "○○ 노선 전용" 한 줄만.

## 세력색 (조사 결과)
- 지도색 기준 ΔE<20 쌍: 190년 25쌍. 이웃 쌍: 사섭-유표(194~207, 10.9), 원술-유표(194, 12.7), 공손강-조조(207, 13.1). 회색·흰색은 0개(규칙 준수).
- 수정안: 팔레트를 27색 이상으로 늘리고, **인접 세력 ΔE≥25(지도 보정 후 기준)**가 되도록 그래프 채색으로 배정. 고정색표 `FAC_COL`은 유지하되 충돌 시 이웃을 바꿈. 회색·흰색 금지 유지.
- 검증: `tools/`에 ΔE 검사 스크립트(시나리오 5종, 인접 쌍 최솟값 출력) — 조사용 `de.js`는 scratchpad에 있음(미커밋).

## 노선별 게이트 전수 (조사 결과)
- 전용 커맨드: 설득=경륜, 동맹 이간=상략, 투항=덕화(민충 80↑), 훈련 행=강병.
- 비용·확률: 등용·이간·내통 성공률 경륜 외 ×0.7 / 매수·매입·조공 상략 외 ×1.4 / 용병비 상략 ×0.8·훈련도 40·유지비 ×1.5 / 국책 소속 노선 100%·그 외 60% / 덕화 진휼·시주 ×1.2·징병 +10%p·점령지 흡수 18개월.
- 교역: 갈래 게이트(`trOpen`), 전용 행동 `drill·mat·arb·wel·armz`, 교역도 증가 상략 ×0.7 외 ×0.35, 인물 발견 경륜만, 사치품 한도 상략 배율, AI 성향 `trIncl`.
- 정리 방침: 숨은 배율은 해당 커맨드 화면에 "○○ 노선 ×0.7" 칩 하나로만 표시. 강병·덕화는 전용 AI 없음(미해결, 별도 설계).
