## 2. 문제 목록 (줄 번호 · 한 줄 수정 제안)

### A. 회색·숨김 설명 부족
1. **계략 탭 안내 거짓** — 13635 `TIPS.t_계략` "내 노선으로 쓸 수 있는 계략만 보입니다"인데 실제로는 기본 7개 전부 보이고(7797) 노선 전용 행만 걸러짐(13629 `s7PlotRows`). 강병은 전용 행이 0개라 탭에 아무 설명이 없음. → 문구를 "내 노선 전용 계략은 맨 아래에 따로 뜹니다"로 고치고, `s7PlotRows`가 강병일 때 "이간·내통 성공률 ×0.7, 매수 비용 ×1.4. 설득·동맹 이간·민심 투항은 다른 노선 전용" 한 줄(dim)을 붙인다.
2. **내정 탭 국책 행이 비아군 도시에서 사라짐** — 13395 `if (!own) return note`가 국책·후계 행까지 막음. → 국책 행을 `own` 검사 밖으로 빼서 항상 보이게.
3. **국책 선택 시트에 노선 표시 없음** — 10236 행에 ★/"60%"가 없고 칩 상세(13367)에만 있음. 강병이 둔전제·구현령 등을 골라도 60%라는 말이 선택 시점엔 안 보임. → 행 `small`에 `RT_POL[p]===rootOf(S.player)?' ★ 100%':' · 60%'` 추가.
4. **학습 시트에서 개성 탭이 사유 없이 회색** — 12611 `dis:!o1`인데 사유 자리 `${o1 ? '' : ''}`가 빈 문자열(양쪽 다 ''). 병종 쪽 12611도 같음. → `${o1?'':' · 경륜 전용'}` / `${o2?'':' · 강병 전용'}`.
5. **상거래 시트 안내 모순** — 12600 머리말 "창고에 둔다 (강병 물자: 구매만)"인데 같은 행 아래 `qb('sellCN', …)` 팔기 버튼이 있음(저자 판매는 `trDealGate`가 `sellCN`을 통과시킴 12470). 또 강병은 `sellTo`·`buyCN`이 차익 게이트에 막혀(12476) 중국 상품 매입과 외국 판매가 통째로 없는데, 12598의 "외국 상거래가 닫혀 있습니다" 경고는 `mat`가 true라 뜨지 않음. → 머리말을 "물자는 사 두었다가 이 도시 저자에 팔 수도 있다"로 맞추거나 팔기 버튼 제거, 그리고 `arb` 거짓 && `mat` 참이면 "차익 거래(중국 상품 매입·외국 판매)는 상략 노선" 한 줄 추가.
6. **교역 단계 목록이 인물·개성을 말없이 뺌** — 12579 `.filter(trOpen)`. → 목록 끝에 `dim` 한 줄 "인물·개성은 경륜 전용".
7. **외교 탭 매입·조공 설명에 비용 가중 없음** — 9118 desc. 강병은 `rootCostK`=1.4라 매입 성공률·조공 수령액이 줄어듦(12962·12966)인데 시트엔 표 값(0.6/1/1.4배)만 보임. → 강병·덕화·경륜이면 "상략이 아니라 값 ×1.4 상당" 한 줄 추가.

### B. 동작·정합
8. **훈련 미리보기가 강병 ×1.25를 빼먹음** — 실제는 5100 `cmdTrain`(×1.25), 미리보기는 8285 `right:+N`과 8287 `plan` 단계에 없음. 같은 시트 안내 9233도 "훈련도는 매달 1 이상 떨어집니다"인데 강병은 0.5(5108). → 8285·8287에 `*(rootOf(c.owner)==='강병'?1.25:1)` 추가, 9233 문구 "매달 1(강병은 0.5) 이상".
9. **병종 학습의 '해금'이 소비처 없음** — `trUnitFx()`는 null(12246), `trUnits`는 훈련 보정(13531)에만 쓰이고 출진 편성에 없음. 12563 뉴스는 "특수 병종 … 해금", 12612 시트에는 개발 메모 "(출진 정예 반영은 6c)"·"(전투 반영은 범위 밖)"이 플레이어에게 그대로 노출. → 문구를 "해금하면 전선 도시 훈련 월 +0.15 (병종 편성은 아직 없음)"로 바꾸고 6c·범위 밖 메모 삭제. (병종을 실제로 편성하게 만들지는 별개 과제.)
10. **외교 탭의 '강병 노선' 행은 실행이 아니라 읽기 전용 창인데 `>` 가 달린 행** — 13396, 눌러도 `openRootDetail`(설명만). 문구 "자기 방법 성 n/m"은 용어 불명. → 설명을 "전투로 얻은 성 n/m · 눌러서 설명 보기"로, 노선별로 `RT_OWNM` 첫 항목 이름을 쓴다(강병 '전투', 상략 '매수·매입…').
11. **노선 정보 진입점이 정보 탭에 없음** — 13398 목록에 노선·국책이 없고 외교 탭에만. → 정보 탭에 "노선·국책" 행 추가(`rootMenu`).

### C. 문구·수치·용어
12. **매수 행 설명 불일치** — 7797 "도시 값의 절반"인데 실제 15%×(비상략 1.4)=21% (4821, 13074가 시트에서만 바꿈). → 7797을 "도시 값의 15% (상략 외 ×1.4)"로.
13. **강병 상세의 손해 문장이 앞뒤 모순** — 13795 "이간·내통·설득·매수·동맹 이간처럼 전용 계략과 AI 행동이 없다"인데 이간·내통은 쓸 수 있고(성공률 ×0.7, 13797 `K.rate` 줄에서 인정) 매수도 ×1.4로 가능. → "경륜·상략·덕화처럼 노선 전용 계략이 없다(이간·내통·매수는 불이익을 안고 쓴다)".
14. **강병 상세에 국책 대가 누락** — 13791은 정예주의 효과만 적었으나 POL_DESC(6319)에 "인구 80%까지만 뽑아 병력이 적음", 총동원령엔 "훈련이 매달 깎임" 대가가 있음. → 손해 목록에 두 대가를 추가.
15. **죽은 문구 `S7_ROOT.강병`** — 13364 "전투가 가장 강하다 / 손실·유지비가 크고 흡수가 느리다"는 코드로 뒷받침되는 강병 전투 보너스가 없고(정예주의 국책만), 노선이 있는 플레이어는 13845·13846이 `openRootDetail`로 가로채 이 문구가 보이지 않음. → `S7_ROOT`와 `s7Info('root')` 분기 삭제(또는 실제 효과로 동기화).
16. **상략 소개가 이간을 상략 것처럼 씀** — 12687 RT_DESC 상략 "이간·매수·매입·용병"인데 이간은 경륜 1.0, 상략 0.7 (12709). 노선 선택 시트(13026)에서 강병과 비교할 때 오해 소지. → "동맹 이간·매수·매입·용병".
17. **월 보고 용어** — 13077 "강병책 · 자기 방법으로 얻은 성 n / 전체 m"은 다른 곳의 "강병 노선"과 다름. → "강병 노선 · 전투로 얻은 성 n / m".

### D. 확인 결과 문제 없음

- 등용 시트: 노선 보정 이유("노선에 맞는 인재 +8 / 노선과 다른 유형 −10", 3172)가 화면에 설명됨.
