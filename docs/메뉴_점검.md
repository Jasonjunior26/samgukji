## (a) 같은 모양 행인데 실행/정보/이동이 섞인 곳

1. 13631 계략 탭 아래 `s7Row(...,'rtSub')` 3행: 설득·동맹 이간은 "시트 열어 실행", 민심은 "읽기 전용"(이미 보고됨), 그런데 모양은 기존 계략 행(`data-a="sub"`)과 같은 `>` 행. 제안: 노선 전용 행에 `[노선]` 꼬리표를 붙이거나 "노선 계략" 소제목(`kv`)을 추가.
2. 13394 `군사·인사·계략·교역` 탭은 "시트 본문 복사"라 `data-a="sub"`(시트 열기)와 `rtSub`/`trOpen`(이동)/`trFx`(즉시 실행)가 한 목록에 섞임. 특히 교역 탭(13624): '세계 교역'은 이동 행, 그 아래 `trFx` 버튼은 즉시 실행(grid3 버튼) — 제안: 즉시 실행은 확인 문구(비용 이미 표시됨)를 쓰거나 행 모양을 버튼 격자로 일관.
3. 13396 내정 탭: '내정'(시트 이동), `s7OpsHtml`(`opsbar` 이동), '국책·후계'(`s7pol`)가 같은 `s7Row`; 외교 탭 13398 '노선 선택/○○ 노선'도 같은 행인데 정보 시트. 제안: 정보형 행엔 `ⓘ` 꼬리표.
4. 13392 `s7Row`가 모든 행에 `>`를 붙임 — 즉시 실행형(`trFx`는 버튼이라 다름)·정보형 구분 불가. 제안: 인자로 종류(`go/info/exec`)를 받아 오른쪽 기호를 `›`/`ⓘ`/`▶`로.
5. 8434 인사 메뉴에 '장수 이동'·'군단'이 `data-a="sub"` 행으로 삽입, 8610 래퍼가 정규식으로 '장수 이동'·'수송'을 **다시 삭제**(8613)하고 '이동' 문구를 덮어씀 — 서로 지우고 쓰는 래퍼 경합. 제안: 한 곳(8039 부근 메뉴 정의)에서 최종 목록을 정의하고 래퍼는 제거.

## (b) 노선별 숨김/회색 규칙이 제각각

1. 계략 전용 행은 **숨김**(13631: `who === r ? ... : ''`), 교역 품목은 **숨김**(13609 `ks.filter(trOpen)`), 상략 단계 품목은 **숨김→개방**, 계략 공용 행(이간·내통·매수)은 **전 노선 표시 + 확률만 가중**(12708 `rootRateK`, 12707 `rootCostK`), 군사·내정·외교 공용 행은 **전 노선 표시**. 한 메뉴 안에서 "숨김"과 "항상 표시"가 섞임. 제안: 노선 한정 효과는 모두 "표시 + 효과 표기 `×0.7`" 로 통일하거나, 전용 행만 숨기고 가중 행엔 한 줄 안내.
2. 13394 `군사·교역`은 비아군 도시에서 안내문만 띄우고 목록 통째로 숨김, `인사·계략`은 목록은 보이되 일부만 회색(13631 `!own`), `내정`은 안내문. 제안: 네 탭 모두 "목록 표시 + 도시 의존 행만 회색 + 상단 한 줄 안내" 로 통일.
3. 13629 `!own`만 쓰고 13622 trade는 `!own && kindOf==='도시'` 둘 다 사용 — 같은 "내 도시" 판정이 두 가지. 제안: `isOwnCity(c)` 헬퍼 하나로.
4. 노선 없음일 때: 13629 `if(!r) return ''`이라 전용 행 0개지만, 12707 `rootCostK`는 노선 없음을 상략(×1.0), 12709 `rootRateK`는 경륜(×1.0)로 취급 → 노선 없음이 매수·성공률 둘 다 최고 조건(교역은 닫힘). 의도라면 문서화, 아니면 제안: `!r`을 ×1.4/×0.7과 동일하게.
5. 13394 계략 탭 안내문(TIPS 13635 `t_계략`)이 "내 노선으로 쓸 수 있는 계략만 보입니다"라고 하지만 7797 메뉴는 유언비어·이간·화계·교란·내통·매수·첩보망 7개를 전 노선에 보여줌(강병도 이간·내통 보임). 제안: 문구를 "노선 전용 계략만 따로 보입니다"로 고치거나 실제로 필터.

## (c) 같은 개념의 이름·문구·단위 불일치

1. 민충 219회 / 민심 36회: 계략 행 이름 `민심`(13631), 시트 제목 '민심 — 투항 전망'(13064), 설명문은 `민충 80 이상`(13066). 제안: 행·제목도 '민충 투항'(또는 설명문을 민심으로) 중 하나.
2. 노선 설명(13804)에서 매수 "도시값 ×… 타 노선 price(off.cost)"인데 계략 시트 문구(13075 오버라이드)는 모든 노선에 "도시 값의 15%, 성공률 +15."를 고정 출력 — 실제 값은 `0.3*k`(k=1.4이면 21%). 7797 기본 행 문구는 "도시 값의 절반". 같은 매수 값이 3곳에서 3가지로 표기. 제안: 오버라이드가 `rootCostK`로 퍼센트를 계산해 표기.
3. 금 표기: `금 ${fmt}`(189곳) 형태가 주이나 `${n}금/개`(12598 시세, 13건 `N금`)·`금 80` 고정 문구(7797)·`금 500 + 능력치²`(8810)·`금 N` 괄호 표기 혼재. 제안: 행 부제 `금 N` 형식 통일, 단가만 `N금/개` 허용.
4. 같은 기능 두 이름: 노선 설명(13810) "교역 > 물자 구매"/"군량 군비화" ↔ 버튼 이름 '물자'/'군비화'(13611), "연수" ↔ "개성 학습"(13787), 덕화 w 목록 "군량 판매"(13821)는 버튼 없음. 제안: 버튼 이름을 설명문 이름과 맞춤.
5. '세계 교역'(13624 행 제목) ↔ 시트 제목 `${도시} · 교역`(12574) ↔ 행 부제 '상거래·학습·친교' — 시트 안에서는 학습·친교가 하단 버튼, 상거래·시세표·수송이 상단. 제안: 행 제목과 시트 제목 통일.
6. 외교 탭 '노선 선택' 행 부제 "새 게임에서 정함"(13398)인데 행을 누르면 `openRootPick`(13033)이 열려 선택이 가능 — 문구와 동작 불일치(노선 없음일 때만 해당). 제안: 부제를 "아직 안 정함 — 눌러서 선택"으로.
7. `trFxHtml` 정의 2개(13540, 13610): 앞 것은 죽은 코드(제목 '품목 효과 …'가 다름). 제안: 13540~13547 삭제.

## (d) 반응 없는/이유 없는 disabled

1. **13617 `trFxHtml` 버튼**: `trFxWhy`가 구체적 이유 문장을 이미 돌려주는데(13474~13487) 버튼엔 `disabled`만 붙고 이유가 어디에도 안 나옴(`btn`, 6700은 title 없음). 눌러도 무반응. 제안: `btn`에 `title`/부제로 `trFxWhy` 문장 표시(`dis:why` 문자열이면 `title`로 출력).
2. 13631 설득·동맹 이간 행: 비아군 도시에서 `disabled`인데 이유 안내 없음(계략 탭 안내문 없음). 제안: 부제를 `아군 도시에서만`으로 교체.
3. 13624 '세계 교역' 행: 비아군이면 회색+안내문이 따로 있어 이유는 나옴(양호). 단 `!own`만 보고 `kindOf==='도시'`와 같은지 확인(13622 `own` 정의가 이미 포함).
4. 8807 `교습`·`용병` 행(8811): `own` 아니면 `disabled`(이유 없음), 같은 시트의 `이 도시` 행들도 동일(8043 `cityOnly&&!own`). 제안: 시트 상단 한 줄 "아군 도시를 선택해야 ○○ 행이 열립니다".
5. 13052 `openIdan` 쌍 행: 쿨다운이면 `disabled`이고 부제에 남은 개월 표기(양호). 반면 장수 행은 쿨다운 상관없이 선택 가능, 확정 버튼은 문구만 있고 쿨다운 막힘 이유 없음(우리 세력 쿨다운은 시트 설명에 있음). 제안: 우리 세력 쿨다운 중이면 하단 버튼을 `n개월 뒤 가능`으로 회색 처리.
6. 13034 `ACT.rtSub` 사전에 훈련·등용·이간·내통·매수·매입·용병·진휼·시주 키가 있으나 호출하는 행은 설득·동맹 이간·민심 3개뿐 — 나머지 9개는 죽은 코드, 이름 없으면 `(()=>{})`로 **조용히 무반응**. 제안: 9개 삭제하고 미등록 키는 `console.warn`.
7. 교역 탭 노선 없음(또는 닫힌 품목): `trClosedMsg`(13604)가 있으나 행이 숨겨져 아예 안내 없음 — 노선 없음 플레이어는 '고가품'(교역도 문턱이면 회색, 이유 없음 = 1번)만 보임. 제안: 교역 탭 맨 위에 `trRootName` 기반 한 줄 "○○ 노선: 열린 품목 …".
