# 삼국지 조조전 (1998, KOEI) 리서치 — 전투씬 개편 참고용

> 조사일 2026-10-15. 출처: 나무위키(본문/병과/책략/줄거리/선택지/전략 및 팁), 위키백과(영/일), 중국 커뮤니티 수치 분석(Inkit wiki, 轩辕春秋), 공략(ggemguide), 회고 기사(GameRes, ITHome, 163.com).
> 수치 공식은 유저 실측치라 버전마다 조금씩 다를 수 있음. **[기억]** 표시는 웹 출처로 확인하지 못하고 내 기억으로 적은 연출 묘사이므로 영상으로 확인할 것.

## 1. 개요
- 영걸전 시리즈 5번째(코드명 EKD5), 1998-12-11 Windows용. 국내 유통은 비스코. 국내·중국에서 시리즈 최고작으로 꼽히고, MOD가 가장 많은 고전 게임.
- 장르는 SRPG. 내정이 없고 **스토리 → 회의(선택지) → 상점/창고 → 출진 선택 → 전투**를 반복함.
- 연의를 바탕으로 하되 조조의 악행(서주 학살 등)은 순화하거나 삭제함.

## 2. 스토리 구성 (전투 약 40~45개)
| 장 | 내용 | 주요 전투 |
|---|---|---|
| 프롤로그 | 황건적 | 영천 (튜토리얼은 허자장이 진행) |
| 1장 패왕 탄생 (15) | 반동탁 ~ 여포 처형 | 사수관, 호로관, 동탁 추격, 청주 황건, 서주 보복, 복양 1~3, 헌제 구출, 장수 토벌 1~2(전위 사망), 원술 정벌, 서주 구원, 여포 포위(눈) |
| 2장 하북 (10) | 원소 세력 정리 | 서주 침공, 백마, 연진, 관도, 창정, 양산, 여양, 업성, 남피, 유성(곽가 생존 분기) |
| 3장 삼국 정립 | 공통 구간 | 박망파, 장판파, 적벽, 적벽 탈출, 합비, 마초 요격 → **분기** |
| 사실 루트 | 촉·오 멸망, 통일 | 한중·정군산·번성·양평관·검각·성도·백제성·적벽2·유수구·건업 |
| 가상 루트 | 마왕에 빙의된 제갈량 | 관우 영입, 오장원 2에서 원귀 장수들과 최종전 |

- **사실(붉은)/가상(푸른) 게이지**: 두 값의 합은 100. 전투 밖 선택지에서만 2/5/10/20씩 움직임. 마초 요격전 뒤 가상 게이지가 85 이상이면 가상 루트로 감. 사실 루트에서는 사실 게이지 85 이상일 때 제위 선택지가 나오며, 받으면 사실 엔딩, 아니면 중간 엔딩. 메인 메뉴 장식은 엔딩마다 붉은/푸른/노란색으로 바뀜.
- **전투 전 선택지**가 같은 전투를 다른 전투로 바꿈: 승리 조건(전멸/목표 퇴각/조조 탈출), 제한 턴, 원군·복병, 보상 보물이 달라짐. 번호가 클수록 어렵고 보상이 좋음.
  - 예: 원술전에서 "유비에게 군량 요청"을 고르면 20턴 안에 적 전멸. "군량총관 처형"을 고르면 12턴 안에 원술 퇴각, 대신 추가 보상.
  - 예: 관도전에서 군량고를 함락하면 적 방어력이 떨어짐.
- **승리 조건 유형**: 적 전멸 / 지정 장수 퇴각 / 아군 특정 유닛이 맵 끝으로 탈출 / 거점 점령 / N턴 생존 / 설득(인접 후 대화).
- 제한 턴은 1장이 약 20턴, 후반은 30~40턴. **[기억]** 남은 턴이 많을수록 클리어 보너스 자금이 커짐.

## 3. 전투 진행
- 턴은 **아군 → 우군 → 적군** 순서. 유닛마다 이동한 뒤 공격/책략/도구/대기 중 하나를 행동함.
- 출진 인원에는 제한이 있고 일부 장수는 강제 출진.
- **적 레벨 스케일링**: 아군 출진 레벨의 절사평균(최고·최저값 제외)으로 정함. 적 무기는 레벨이 4 오를 때마다 한 단계씩 강해져 32레벨에서 최고 단계.
- **이벤트**: 특정 장수끼리 인접하면 대화나 **일기토**가 발생함. 연의를 재현하며, 관우가 화웅·안량·문추를 일격에 베는 장면이 대표적. 일부는 동작 없이 서로 한 대씩 치는 "소일기토". 일기토 대상이 되면 즉시 퇴각하거나 사망하기도 함.
- 퇴각한 아군 장수는 다음 전투에 복귀함. 단 특정 전투의 전위·곽가처럼 스토리상 사망하는 경우가 있음.
- 마을·병영 칸은 매 턴 HP 회복. 보물고 칸이나 적 격파로 보물을 얻음.
- 날씨는 맑음/흐림/비/눈. 비나 눈에서는 화계가 불가하거나 약해짐. 일부 책략은 날씨를 조건으로 함.

## 4. 능력치와 공식
**5대 능력치 → 전투 수치**: 무력→공격력, 지력→정신력, 통솔→방어력, 민첩→순발력(폭발력), 운→사기.
- 병과마다 공/정/방/순/사의 성장 등급이 S/A/B/C로 정해져 있음.
- 원 능력치가 일정 구간(70, 90 등)에 못 미치면 레벨업 때 성장이 둔해짐. 열매 아이템으로 이 구간을 맞춰 키움.
- 공격력 = 무력/2 + 레벨 × 등급계수 + 무기 공격력.

| 항목 | 공식 |
|---|---|
| 물리 피해 | `[(공A×지형 − 방D×지형)/2 + 공격자Lv + 25] × 상성계수 × 무기계수`, 실제 값은 −2~+4로 흔들림, 최소 1 |
| 책략 피해 | `[(시전 정신 − 대상 정신)/3 + Lv + 25] × 책략계수 × 병과계수`, 지형 보정 없음 |
| 반격 | 일반 공격의 약 75~80%. 반격은 연속공격 확률이 0 |
| 회심 | 피해 150%, 유닛이 번쩍임. 확률은 사기 비율로 정함 |
| 연속공격 | 2회 공격. 확률은 순발력 비율로 정함 |
| 명중 | x = 공 순발 / 방 순발. x≥2이면 100, 1~2이면 10x+80, 0.5~1이면 60x+30, 1/3~0.5이면 90x, 그 미만은 30 (%). 대상이 혼란이면 100% |
| 회심/연속 확률 | x = 비율. x≥3이면 100, 2~3이면 80x−140, 1~2이면 18x−16, x<1이면 1 (%) |
| 책략 명중 | 기본은 (정신+사기) 비율로 구한 뒤 책략별 계수(1/0.9/0.8/0.6/0.5/0.33)를 곱함 |
| 회복 | 소보급은 40 + 정신/10, 대보급은 70 + 정신/2 |
| 상태이상 자연 회복 | 매 턴 확률 = 운/2 (최대 50%) |

- **경험치**: 공격, 반격, 막타, 책략(회복·버프 포함)으로 얻고, 레벨 차가 클수록 많이 얻음. 막타 경험치가 큼.

## 5. 병과 (아군 13계열, 레벨 15와 30에 승급해 3단계)
| 계열 | 단계 | 이동 | 특징 |
|---|---|---|---|
| 군주 | 군웅→영웅→패왕 | 6→7 | 조조 전용, 전 능력 A, 영웅부터 대각선 공격, 패기 |
| 기병 | 경기병→중기병→친위대 | 6→7 | 공격 S, 평지 강함, 산·습지 약함 |
| 궁기병 | 궁기병→노기병→연노기병 | 6→7 | 기동형 간접 공격 |
| 보병 | 경보병→중보병→근위병 | 4→5 | 최고 HP·방어, 대각선 공격 가능 |
| 궁병 | 궁병→노병→연노병 | 4→5 | 사거리 넓음, 반격을 받지 않음 |
| 적병 | 적병→의적→호걸 | 5→6 | 산·숲 강함, 지계·욕설 |
| 무도가 | 무도가→권사→권성 | 5→6 | 순발 S |
| 무희 | 무용수→무희→무녀 | 5→6 | 주변 아군 상태이상 자동 해제, 유혹 |
| 포차 | 경포차→중포차→벽력차 | 3→4 | 범위 공격, 근접에 매우 약함 |
| 책사 | 책사→참모→군사 | 4→5 | 공격 책략 |
| 도사 | 도사→환술사→요술사 | 4→5 | 방해 책략(허보, 팔진도) |
| 풍수사 | (3단계) | 4→6 | 회복 |
| 기마책사 | 기마책사→기마참모→기마군사 | 6→7 | 사마의 전용, 날씨 책략 |

적 전용 병과: 서량기병, 황건적, 해적, 곰부대, 맹호대, 제독, 주술사, 선인, 나무인형/흙인형, 식량대, 황제, 민중.

**상성**: 기병 → 보병 → 궁병 → 기병 순으로 유리.
- 보병이 궁병·포차를 치면 ×1.5.
- 궁병·궁기·포차가 기병·맹수를 치면 ×1.5.
- 보병이 기병을 치면 ×0.6.

## 6. 지형 (밟을 수 있는 18종, 통행 불가 12종)
- 밟을 수 있는 지형: 평지, 초원, 숲, 황무지, 산지, 설원, 다리, 여울, 습지, 대하, 성내, 요새, 마을, 병영, 가옥, 보물고, 성, 관문.
- 통행 불가 지형: 바위산, 벼랑, 연못, 강, 울타리, 성벽, 성문, 도랑, 불, 배, 제단 등.
- 병과×지형마다 **이동 비용(1~3)**과 **공·방 보정**이 있음: ★120%(성·관문·요새) / ◎110% / ○100% / △90% / ×80%.
  - 기병: 평지◎1, 숲△2, 산지×3, 습지×3.
  - 보병: 모든 지형 ○1~2.
  - 적병: 숲·산◎1.
  - 해적: 물◎.
- 책략은 속성마다 쓸 수 있는 지형이 정해져 있음.
  - 화계: 평지·초원·숲·성 등.
  - 수계: 물·습지·설원.
  - 지계: 황무지·산지.
  - 풍계: 숲·성을 뺀 야외.
  - 다리는 화·수·풍 모두 가능.

## 7. 책략 (MP 소모, 사거리, 범위: 단일/십자/사각/직선/전체)
- 공격: 화계(초열→업화→화진→화룡→폭염), 수계(탁류→…→해일 즉사), 지계(낙석→…→거암 120%), 풍계(선풍→…→모래폭풍 맵 전체).
  - 1단계는 MP 6, 사거리 4, 위력 70%. 상위 단계일수록 범위가 넓어지고 명중이 낮아짐.
- 버프(3턴): 연병(민첩), 고양(사기), 분기(공/정), 견고(방어), 기합(자신), 패기(조조).
- 회복: 소보급, 대보급, 구원대, 구원군, 수송(거리 무제한), 조언·헌책(MP 전달).
- 보조: 각성(해제), 강행(이동 +2), 회귀(재행동).
- 디버프(−30%): 둔병, 허탈, 압박, 욕설과 각각의 광역판.
- 상태이상
  - 독: 매 턴 피해, HP는 1까지만 깎임.
  - 부동: 이동 불가.
  - 금책: 책략 불가.
  - 혼란: 행동 불가, 공격을 반드시 맞음, 반격 불가.
- 사신(보옥 보물 필요, MP 40): 주작(맑음), 청룡(비·눈), 현무(흐림), 백호.

## 8. 장비와 보물
- 상점 장비는 무기·방어구 각각 나무→구리→철 3단계(단계마다 Lv1~3)이고, 상위 단계는 특정 전투 이후에만 해금됨.
- 장비는 사용하며 경험치가 쌓여 강화되고, 다 키운 장비를 팔면 열매를 얻을 수 있음.
- 보물은 50종으로 전투마다 대략 1개 얻고 최대 9레벨까지 성장. 보물도감을 완성하면 2회차에 전부 들고 시작.
- 보조 아이템 예: 콩주머니(자동 회복), 태평청령서(상태이상 해제), 구리기마갑옷(간접 피해 반감).

## 9. 연출 (전투씬 개편의 핵심) — **[기억] 영상으로 확인 필요**
- 별도 전투 화면으로 전환하지 않음. **맵 위에서 바로** 공격자가 대상 쪽으로 돌아서 공격 모션을 짧게 재생함. 맵 이동용 스프라이트와 공격 동작용 스프라이트가 따로 있음(MOD 용어로 R형상/S형상).
- 맞는 쪽은 방어(막기) 모션이나 피격 모션을 보이고, 이어 HP 게이지 창이 줄어드는 연출이 나옴. 반격이 있으면 같은 방식으로 이어짐.
- 회심은 공격자가 하얗게 번쩍인 뒤 강한 타격. 연속공격은 두 번 공격. 막기는 방어 모션과 함께 피해 감소.
- 책략은 대상 칸 위에 이펙트(불·물·바위·바람·광선)를 겹쳐 재생함.
- 퇴각할 때 초상화 대화창에 장수별 퇴각 대사가 나오고 유닛이 사라짐. 레벨업할 때는 능력치 상승 창.
- 이벤트 대화는 초상화 + 이름 + 대사창 형식이고, 맵 위 유닛이 대사에 맞춰 움직이며 연기함(이동, 방향 전환, 놀람 모션).
- 일기토는 두 장수가 마주 보고 번갈아 공격한 뒤 대사, 결과(참살/도주) 순서로 진행.
- 템포가 빠른 편이고(한 번 공격에 약 1~2초), 수치는 HP 바와 숫자로 간결하게 보여줌.

## 10. 평가 요약
- 장점: 병과·지형·날씨·상성이 맞물리는 전술 깊이, 선택지로 같은 전투가 달라지는 리플레이성, 연의 장면 재현(일기토·인접 대화), 조조 재해석, 파고들기(보물도감, 열매, 압급 레벨링).
- 단점: 장비 해금과 레벨링 구조가 불합리, 보물 밸런스 편차, 무력과 일기토 결과의 괴리, 조씨 일족이 약함, 번역 오역.
- 플레이어 기억에 남는 장면: 전위·곽가의 죽음, 관우의 일격, 박망파·적벽의 공포, 연구와 반복 도전의 재미.
