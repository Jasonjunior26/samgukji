## 버전업 기록 규칙

요소(전투/내정/외교/인사/AI/UI) 하나를 버전업할 때마다:

1. 해당 `docs/변화_*.md`의 **"현재 상태 요약"** 단락을 지금 사실에 맞게 고친다.
2. 그 아래 버전 기록의 **맨 위**(최신이 위)에 새 항목을 추가한다. 형식:

```
## vX.Y (YYYY-MM-DD) — 한 줄 제목
### 변경 사항
- 무엇을 어떻게 바꿨는지 (함수·설정 이름 포함)
### 시뮬레이션·검증 결과
- 수치 (승률, 평균 턴, 손실 비율, 처리 시간 등)
- 사용한 도구·명령 (예: `node tools/battle_sim.js 20`), 시드나 반복 횟수
- 돌리지 못했으면 사유
### 알려진 문제
- 남은 빈틈, 미확인 사항은 "미확인"으로 명시
### 관련 커밋
- 해시 (여러 개면 모두)
```

3. 코드 줄 번호가 바뀌었으면 `docs/코드지도.md`를 갱신한다.
4. 설계 문서(예: `전투_설계_v4.md`)의 현황 절이 있으면 거기에도 한 줄 남긴다.
5. `git add docs/ CLAUDE.md samguk_v107.html tools/` 뒤 커밋. `screenshots/`와 `assets/`는 커밋하지 않는다.

버전 번호는 요소별로 따로 센다(전투 v4.x, 내정 v1.x …). 게임 전체 버전(`BUILD`)과는 별개다.

**지어내지 않는다.** 코드·git 이력·실행 결과에서 확인한 것만 적고, 확인 못 한 것은 "미확인"으로 쓴다.
