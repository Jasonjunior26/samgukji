## 1. 구현 방식 (결정)
- 새 코드는 **패치 블록 끝, V4 블록(12016) 앞**에 `<script>` 블록 하나(`// ===== v107 S5: 뿌리·국책 장치 =====`)로 넣고 래퍼로 덧씌운다. V4 블록·jojo 자산 블록은 건드리지 않는다.
- 원본 직접 수정은 매수 가격식(4779 `cityPrice(tc) * 0.5`)과 매수 UI 값 표시(9063)만.
- 월 흐름: `endMonth`(1071, AI `aiTurn` 호출) → 방어전 → `monthlyUpdate`(1079, 7064·7578에서 호출). AI 장치 행동은 `aiTurn` 래퍼 **앞**(장수 소진 전), 월 판정(포섭 판정·투항·용병 만료)은 `monthlyUpdate` 래퍼 **앞**, 파급·법치/덕치 가중 보정은 **뒤**.
- 뿌리 없음(`root` 미정)은 모든 가중 1.0(중립). 플레이어는 새 게임 직후 시트에서 고름, AI는 `newGame` 래퍼에서 지정표→자동.

### 국책 ↔ 뿌리 (§17-4, 총동원령은 강병으로 둠 — 가정)
경륜: 구현령·공신 우대 / 강병: 정예주의·총동원령 / 상략: 상업 진흥 / 덕화: 덕치·법치·둔전제

### 지정표(세력 id)
경륜 조조·원소·유표·유우·공융·왕랑 / 강병 동탁·공손찬·마등·한수·맹획·엄백호 / 상략 손견·손책·사섭·원술·포신·공손도 / 덕화 유비·도겸·유언·유장·장로. 나머지는 자동(능력 점수 표준화 + 덕화 +0.4).
자동 점수: 경륜 i+p, 강병 w+t, 상략 c×1.6, 덕화 (p+t+c)×0.7 → 시나리오 생존 군주 평균·표준편차로 표준화.
